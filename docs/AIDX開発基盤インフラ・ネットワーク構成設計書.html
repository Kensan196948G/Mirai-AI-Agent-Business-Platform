承認済み基本方針

採用方針： 開発PCは既存会社貸与PCを利用し、本社内FortiGate配下の既存社内ネットワークに置いたままとする。 新規にAI/DX用ネットワークを分岐し、サーバ側のみをVLAN分離する。
Corporate LAN

Security Boundary

FortiGate

既存LANとAI/DX VLAN間の通信制御、IPS、ログ、ポリシーの中心。

Server Segmentation

AI/DX VLAN

管理サーバとAI Devサーバを分離。将来STG/PRODへ拡張。

拡張判断

Phase 1
既存LAN + VLAN110 MGMT + VLAN120 AI-DEV。開発・検証開始。
Phase 2
STAGING / PRODUCTION / BACKUP / MONITORを分離。本番運用開始。本設計書はVLANアドレス空間の予約（設計）のみを承認するものであり、MONITOR（監視基盤）の実際の構築着手はai-dx-dev-saas-setup-guide.md P-6（誰が・いつ作るか）の決定を起票条件とする。
Phase 3
Integration Hub / Webhook / DMZ。必要な自動連携が発生した時だけ追加。
Phase 4
SSO / MFA / Conditional Access / OOB管理 / 冗長化を拡張。

最終構成要約

既存LAN維持開発PCは会社貸与PC・既存ネットワークのまま
2 VLAN開始VLAN110 MGMT / VLAN120 AI-DEV
FortiGate中心VLAN間通信・Policy・IPS・Log
10GbE基幹Server / NAS / Switch Backbone
最終採用案：
既存社内ネットワークは変更せず、会社貸与の開発PCは既存LANに配置する。 FortiGateからAI/DX用ネットワークを分岐し、L2/L3 Managed Switch配下に VLAN110（管理サーバ）とVLAN120（AI Dev Server）を構築する。 VLAN間・既存LAN間通信はFortiGateのFirewall Policyで制御し、将来の本番運用時にSTAGING / PRODUCTION / MONITOR / BACKUPを追加する。
