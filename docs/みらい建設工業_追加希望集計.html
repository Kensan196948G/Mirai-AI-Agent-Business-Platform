みらい建設工業 Agent／Skill 追加希望 集計・優先度付け

各部署が「部署別 Agent／Skill 機能一覧シート」で保存した JSON（JSON 書き出し）または HTML（名前を付けて保存）を読み込み、追加希望を一覧化して優先度・状態を付けます。外部通信はありません。判断内容はこのブラウザに自動保存され、「名前を付けて保存」で HTML として持ち出せます。
ここにシートのファイル（JSON / HTML）をドロップ、または「シートを読み込む」から選択してください。同じ部署のファイルを再度読み込むと、その部署の希望は最新の内容に置き換わります（優先度・状態の判断は保持されます）。
組織Agent種別希望内容提出元優先度状態担当・備考
優先度・状態・備考は「希望内容 × Agent × 種別」ごとに保存されます。同じ文言の希望が複数部署から出ている場合は「重複 n 件」と表示します（集計の重み付けの参考）。P2/P3 の Agent は候補（未実装）であり、採用判断は各専門 Owner のレビューと評価資料を前提とします。
