MIRAI-AGENTOS / AGENT & SKILL GUIDE

Agent（エージェント）と Skills（スキル）
全社員向け説明資料

Mirai-AgentOSで使うAgent（専門家役のAI）とSkills（そのAIが使う能力）を、会社組織・土木建設専門分野・人間の確認ポイントまで含めて、IT部門以外の社員にも分かりやすく整理した資料です。

01

まず理解する：AgentとSkillの違い

一番簡単な考え方： Agent（エージェント）は「専門家役」、Skill（スキル）は「その専門家が使う能力」です。
Agent / エージェント

専門家役

複数の情報やSkillを使って考え、仕事を組み立てます。

Skill / スキル

専門能力

数量算出、基準検索、施工計画レビューなど、具体的な能力です。

Knowledge / ナレッジ

知識

基準、過去事例、ADR、研究結果、Playbookなど。

Tool / ツール

道具

CAD、GIS、計算、GitHub、検索など実際の処理手段。

Policy / ポリシー

ルール

AIに任せてよい範囲と、人が必ず確認する範囲。

例：構造技術Agent / Structural Engineering Agent
        │
        ├─ 擁壁レビューSkill / Retaining Wall Review
        ├─ 杭基礎チェックSkill / Pile Foundation Check
        ├─ 荷重組合せ確認Skill / Load Combination Check
        │
        ├─ Knowledge / 知識
        │    ├─ 設計基準
        │    ├─ 過去案件
        │    └─ 技術判断記録
        │
        └─ Tools / 道具
             ├─ 計算ツール
             ├─ CAD
             └─ 解析ソフト

AIに任せる範囲と、人が確認する範囲

技術リスクAIの利用例人の確認
T0情報検索 / Information Search通常確認
T1要約・整理 / Summarization内容確認
T2設計候補・施工案 / Draft Proposal担当者レビュー
T3計算・技術レビュー / Engineering Review専門技術者レビュー
T4重要な設計判断候補 / Important Engineering Decision専門技術者必須
T5安全・構造に関わる重大判断 / Safety-Critical DecisionAI単独承認禁止
T6最終設計・最終施工判断 / Final Design & Construction Decision人間が最終決定
08

AgentとSkillを増やすときのルール

Agentにする条件

  • 独立した責任がある
  • 複数Skillsを組み合わせる
  • 独自の判断基準がある
  • 他Agentとの責任境界がある
  • 独立した評価が必要

Skillにする条件

  • 1つの具体的な処理
  • 複数Agentから再利用できる
  • 入力と出力を明確にできる
  • テスト可能
  • 人の確認条件を定義できる

最終イメージ

組織Agent = 「誰の仕事か」
土木専門Agent = 「何の専門家か」
Skill = 「何ができるか」
Mirai-AgentOSの狙い： 各部門の仕事をAIに置き換えるのではなく、人が持つ責任・専門性・判断を尊重したうえで、AIが情報整理・専門支援・横断連携・知識再利用を担うことです。
